# 📚 TinderForBooks

*TinderForBooks* is an interactive web app concept inspired by swipe and matching mechanics from modern dating apps.
Instead of discovering people, users discover books through personalized recommendations and interactive swipe-based decisions.

By selecting preferences such as genre, author, or book length, the application creates a more modern, engaging, and personalized approach to digital book discovery.

The project combines creative product ideas with frontend development, database integration, and interactive user experiences.

---

## ✨ Features

* ➡️ Swipe-based like / dislike interactions
* 📘 Display of books with title, author, and cover
* 🎯 Personalized recommendations based on user preferences
* 👤 User accounts and authentication system
* 💾 Database and storage integration with Supabase
* 🔄 Dynamic loading of new content
* 🎨 Modern and intuitive user interface
* 📱 Focus on interactive and easy-to-use navigation
