# 📚 TinderForBooks

*TinderForBooks* ist eine kleine Web-App, die das Prinzip von Tinder auf Bücher überträgt.  
Statt Menschen nach links oder rechts zu swipen, entscheidest du hier über Bücher –  
gefällt es dir, oder nicht?

Dieses Projekt dient als Übung für Webentwicklung, Design und das Zusammenspiel von Frontend-Frameworks.

---

## ✨ Features
- ➡️ **Swipe-ähnliche Interaktion** (Like / Dislike)
- 📘 Bücher werden mit **Titel, Autor und Cover** angezeigt
- 🔄 Dynamisches Laden neuer Bücher
- 🎨 Einfache, intuitive UI für schnelle Entscheidungen
- 🌐 Modernes Frontend-Setup (je nachdem was du nutzt: React / JS / CSS etc.)

---

## 🛠️ Tech Stack
- **JavaScript / TypeScript** (abhängig von deinem Code)
- **HTML & CSS**
- **React** (falls du es nutzt)
- **TailwindCSS** (optional – bitte bestätigen)
- **API für Bücher** (falls du eine verwendest – sonst "Mock-Daten")
